

This is an online bookstore/e-commerce website ("Bookshop") built with plain CSS (no Bootstrap this time) using flexbox layouts. Green/orange color scheme (
#4E7F16 green, 
#FD7F04/
#F36C00 orange). It has a multi-tier navbar structure typical of e-commerce sites. Here's the section-by-section breakdown:

1. Top Utility Navbar (navbar)
Dark green strip with 3 parts: left — Online Store, About Us, Delivery, FAQs, Contacts links; center — phone icon + number; right — Wish List, Shopping Cart, My Account, lock icon
2. Search/Cart Navbar (navbar1)
Light green background with: a search input box, a logo/icon, a "Free Delivery" box icon, a running total ("$345.39 / 2 items"), and a shopping basket icon
3. Category Navbar (navbar2)
A simple horizontal menu: Books, Textbooks, Nook Books, Audiobooks, Magazines, Movies, Music, Games
4. Hero Section (hero-section, orange background)
Left: a banner image
Right: tagline text "Hezy Theme: What We Can All Do to Save America's Future" + a green "VIEW MORE" button
5. Info Cards Section (latest-product)
3 flex cards side by side: "SHOP SALE" (up to 75% off), "LATEST PRODUCTS" (new arrivals), "READ THE BLOG" (latest hot news) — each card gets a background image on hover
A decorative shadow strip below
6. Bestsellers Section (best-sellers)
"Bestsellers" heading + 5 product cards in a row, each with: book image, title, author, price, and an "add to basket" button
7. Testimonials Section (testimonial, light grey background)
"Customer testimonials" heading + 2 testimonial cards, each with review text (bordered box) and a reviewer photo + name + company below
8. Latest Products Banner (latest-products-section)
"Latest products" heading + a large banner image + a centered tagline about WordPress themes
9. Features Section (features)
Two rows of 2 feature blocks each (4 total): each has a title, horizontal divider, a circular icon image + description text, and a "FIND OUT MORE →" link
10. Category Sliders Section (sliders)
3 large image tiles: SALE, GAMES, LOOKBOOK — text is hidden by default and fades in with a colored overlay on hover
11. Blog Section (blogs)
"From the blog" heading + 2 blog entries, each with an image on the left and title + comment count + description on the right
12. Footer (footer-sec, dark background 
#1D2124)
4 columns:
About This Site — logo/image + description text
Categories — two sub-lists (Books/Textbooks/etc. and Movies/Music/Games)
Information — two sub-lists (Track Order/Delivery/etc. and Contact/FAQ/etc.)
Connect — social icons + newsletter email signup with a green "Subscribe" button
13. Bottom Footer Bar (footer-bottom)
Left: small icon image; Right: copyright text "©2014 BOOKSHOP. ALL RIGHTS RESERVED." + "Made with love by Hezytheme" + a "TOP" scroll-up link
